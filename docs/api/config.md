## CONFIG : <code>object</code>
Configuration object for monster collection synchronization.IMPORTANT: Add the names of all sheets you want to synchronize into this list.The script assumes for ALL these sheets:- Column A contains the checkboxes.- Column B contains the monster names.

**Kind**: global constant  
**Properties**

| Name | Type | Description |
| --- | --- | --- |
| syncSheetNames | <code>Array.&lt;string&gt;</code> | Names of sheets to synchronize checkboxes across. |
